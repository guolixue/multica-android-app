# Multica Android App

Standalone Expo / React Native client for [Multica](https://github.com/multica-ai/multica), extracted from the Multica monorepo. This repo contains the mobile app (`apps/mobile/`) plus the `@multica/core` package it depends on, so it builds as a self-contained workspace.

## Structure

- `apps/mobile/` — the Expo app (iOS + Android). Source of the Android APK builds.
- `packages/core/` — shared business logic, API client, types, pure helpers (runtime dependency of the app).
- `packages/tsconfig/`, `packages/eslint-config/` — workspace tooling configs referenced by `@multica/core`.

## Prerequisites

- Node.js + pnpm 10 (`packageManager: pnpm@10.28.2`)
- Xcode for iOS, Android SDK for Android
- See `apps/mobile/README.md` for the full build / device-install guide.

## Setup

```bash
pnpm install
```

Env files are committed for staging and production (`apps/mobile/.env.staging`, `apps/mobile/.env.production`). For a local backend, copy `apps/mobile/.env.example` to `apps/mobile/.env.development.local` and set `EXPO_PUBLIC_API_URL` to your machine's LAN IP.

## Scripts

From the repo root (all delegate to `apps/mobile/`):

| Command | What it does |
|---|---|
| `pnpm dev:mobile` | Metro only (local backend) |
| `pnpm dev:mobile:staging` | Metro only (staging) |
| `pnpm dev:mobile:prod` | Metro only (production) |
| `pnpm ios:mobile` | Rebuild + install on iOS Simulator (local) |
| `pnpm ios:mobile:staging` | Rebuild + install on iOS Simulator (staging) |
| `pnpm ios:mobile:prod` | Rebuild + install on iOS Simulator (production) |
| `pnpm ios:mobile:device` | Full rebuild + install on USB iPhone (local) |
| `pnpm ios:mobile:device:staging` | Full rebuild + install on USB iPhone (staging) |
| `pnpm ios:mobile:device:prod` | Full rebuild + install on USB iPhone (production) |
| `pnpm ios:mobile:device:prod:release` | Release build to USB iPhone (production) |
| `pnpm typecheck` | TypeScript check (mobile) |
| `pnpm lint` | ESLint (mobile) |
| `pnpm test` | Unit tests (mobile) |

> Android: the `android/` native project is generated by Expo prebuild (gitignored). Run `pnpm exec expo prebuild --platform android` (or EAS build) to regenerate it, then build via Gradle — matching how the APK was produced in the source workspace.

## Android release APK

From `apps/mobile/android` after prebuild:

```bash
ANDROID_HOME=/path/to/android-sdk ./gradlew assembleRelease -PreactNativeArchitectures=arm64-v8a
```

Output: `apps/mobile/android/app/build/outputs/apk/release/app-release.apk` (package `ai.multica.mobile`, version `0.2.0`).
